# 报价身份约定

- `报价记录ID` 形如 `VPN-Axxxxxxxxxxxx-yyyyyyyy`。
- `VPN-Axxxxxxxxxxxx` 是稳定产品锚点。它只使用供应商、产品系列、SKU、产品类型、账期、币种和 IP 配置，不包含价格、库存、核验日期或地区分组。
- 末尾八位是本次公开报价的地区范围标识。供应商调整同价地区分组时，这部分可能改变。
- 用户选定方案后，同时保留产品锚点和用户确认的 ISO 国家代码、城市或机房。二次核价时先用完整报价 ID，失败后用产品锚点加用户确认地区恢复。
- `offer-id-aliases.json` 将第一版旧 ID 映射到当前 ID，供现有对话和已保存推荐迁移。
- 若产品锚点对应多条记录，不可凭第一条自动下单。必须用用户确认的地区筛选，并在官网再次核对 SKU、地区、账期和 IPv4 配置。
